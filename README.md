# Enroute

- This server will be responsible for handling logic involving riders' delivery and payment for their services.

## Getting Started

### Prerequisites

- Node.js
- yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/LiquidHackGroup/enroute-server.git
   ```

2. Navigate to the cloned project:

   ```
   cd enroute-server
   ```

3. Install dependencies:

   ```
   yarn
   ```

4. Start the development server:

   ```
   yarn start
   ```

5. To access the docs:

Visit [https://enroute-server.onrender.com/api-docs](https://enroute-server.onrender.com/api-docs)
